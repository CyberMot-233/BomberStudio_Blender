# 更新检查与安装

当前操作流程：**手动检查 → 立即更新 → 确认 → 下载与校验 → 备份安装 → 重启 Blender**。

完整过程见 [一键在线更新教程](./一键在线更新.md)。

- 旧版 1.1.x 需要先用本地 ZIP 安装 1.2.0 并重启一次，之后才能在线更新。
- 仓库默认是 `Hoshino486/BomberStudio_Blender`，支持完整 GitHub 地址和自定义仓库。
- 更新器比较正式 Release 的 Tag，不把标题或 ZIP 文件名当成包内版本。
- 发现新版本后显示立即更新按钮；缺附件、缺校验值或元数据异常会显示原因。
- 不在启动时检查，不静默安装，不自动关闭 Blender；下载和备份使用设置中的临时目录。
- 老版 1.1.0 对完整地址有输入限制，先填 `Hoshino486/BomberStudio_Blender` 简写即可检查。

发布操作见 [GitHub发布步骤](./GitHub发布步骤.md)，自定义版本见 [版本与发布内容](./自定义版本号与发布内容.md)。
