### 实际检查

- **150/150** 既有功能回归；**24/24** ASCII FBX 专项。
- **45/45** Source 专项与旧版隔离检查，其中现代版本包含独立插件共存。
- **64/64** 安装后 Source 检查，直接执行安装后的传统 / `bl_ext` 命名空间代码，而不使用工作区代码替代。
- **32/32** Python 单元检查（27 项既有检查 + 5 项版本、语法隔离、来源许可和 ZIP 一致性检查）。
- Blender **4.5.5 与 5.2.2** 的 Extension 元数据验证器通过。
- ZIP CRC、源码与 ZIP 逐文件核对通过；同一输入重复打包应得到相同 SHA256。
- 核心模块保持 Python 3.5 语法；内置提供者包含新语法并被严格隔离，不宣称它可由 Python 3.5 直接解析。

#### Source 专项的内容

1. 内置提供者注册及更新器转交父插件。
2. 三轮启用 / 停用，无重复或残留事件回调、RNA 类和九个顶点映射算子；三个顶点映射实际创建 / 删除。
3. SMD 网格、UV、材质、骨骼、权重导入。
4. 动画附加到现有骨架，新增 0 网格仍正常完成。
5. SMD / VTA 导出并重新导入，断言形态键具有真实顶点位移。
6. 二进制 DMX 5 / model18 往返，检查网格、骨架、权重与 smile 形态键。
7. QC 引用 QCI、参考 SMD 与动画 SMD；没有调用外部游戏编译器。
8. 缺失文件、未设输出目录、损坏 DMX 的错误处理与偏好恢复。
9. 部分注册失败仅回滚本副本拥有的类。
10. 已启用独立提供者时复用；停用 BomberStudio 后外部提供者仍在。

#### 安装测试还检查

真实 ZIP 安装、注册阶段受限上下文、ASCII 三角形转换、平滑法线 UV、用户目录回退、本地 ZIP 更新及回滚、禁用 / 重新启用。

### 本次调试记录

首轮记录保留在本机临时目录，没有把重试记成首次成功：

- 上游九个顶点映射算子在模块导入时注册且没有注销：已改为收集类并加入统一生命周期；独立版共存再验无覆盖注册。

- 查询不存在的算子会抛出 `KeyError`：已补齐兼容层处理。
- 集合中的选中网格应按 Source 导出单元导出：已按集合调度。
- Blender 5.2 非零形态键污染参考网格，导致 VTA 空形变：已在参考烘焙前固定 Basis。
- 正式安装器的 `_RestrictContext` 没有场景：注册时只定义资源，场景刷新推迟到正常上下文。
- 深层证据目录超过 Windows 路径长度限制：安装回归改用指定临时文件夹内的短路径；没有修改系统长路径策略。
- 打包语法检查读取上游 BOM 文件失败：改用 `utf-8-sig` 解析，原始文件字节仍保留。

### 范围与复现

测试没有覆盖未列出的 Blender、macOS/Linux、全部复杂模型与 DMX 变体、所有 Source 游戏或真实 SDK 编译；保留高级功能源码不等于完成所有高级工作流的游戏内验收。
面板接口检查不等于逐版本人工点击全部 UI。完整数据见 [兼容验证.json](./兼容验证.json)。
