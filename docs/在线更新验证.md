## 覆盖内容

- 检查不会下载；发现新版且附件可验证后显示“立即更新”。
- 自定义仓库、完整网址、仓库大小写、过期检查、离线模式、404、限流、损坏 JSON。
- Universal 优先；普通同版本 ZIP 兼容；不选择 GitHub 自动生成的源码包。
- GitHub SHA256、同 Release 校验文件回退、截断/超限/错误内容、取消和超时。
- ZIP 目录、大小、符号链接、大小写冲突、缓存过滤、内部版本与 Release Tag 一致性。
- 实际下载算子、备份、事务替换、重启提示、恢复旧代码；失败不覆盖现有代码。
- 备份失败、目录切换失败、安装回执写入失败和并发锁的故障注入回归。
- 确认框在工作线程创建之前取消，仍正常结束，不报缺失 `_job`。
- Python 3.5 语法兼容与现代 Source 提供者延迟加载隔离。

## 复核入口与范围

开发工具使用 Python 3.13。模型/安装测试需要对应的 Blender 运行时；
`tools/run_matrix.py` 的运行时路径按开发环境配置，迁移机器后应调整。

```powershell
py -3.13 tools/build_release.py
py -3.13 -m unittest discover -s tests -p "test_*.py" -v
py -3.13 tools/test_universal.py
```

联网检查默认不运行；显式设置 `BOMBER_LIVE_UPDATE=1` 后，安装矩阵会额外调用一次 GitHub。
实际 GUI 测试脚本为 `tests/online_modal.py`，冷启动脚本为 `tests/online_restart.py`。

只声明上述实测版本，不承诺所有历史/未来版本、所有 OS 或每台机器的网络证书环境。
下载校验并非发布者身份的独立签名；仍应确认自定义仓库来自可信的插件维护者。
